Cyberbullying Detection and Prevention System

A student-focused platform for identifying, reporting, and reviewing harmful online messages.

About the system

This system helps the institution identify possible cyberbullying in messages submitted through the student portal. Each message is analysed automatically and the result is saved so that authorised staff can review patterns, alerts, and reports.

The system supports early awareness and responsible intervention. It assists staff with reviewing messages, but an AI result should not be treated as the only decision about a student.

How it works

1. Submit a message

A student signs in and submits a message through the student portal.

2. Automatic analysis

The detection model checks the message and returns a classification with a confidence score.

3. Review and report

Students can report a concern, while authorised administrators review alerts and reports.

What the system provides

Message detection

Flags messages that may contain cyberbullying-related language for further attention.

Student history

Students can view their recent submissions, results, confidence scores, and dates.

Administrator review

Administrators can monitor activity, review alerts, manage reports, and study trends.

For students

Sign in to submit a message, see the analysis result, review your recent posts, and report a message that needs attention.
